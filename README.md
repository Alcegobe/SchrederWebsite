# Schréder — Homepage (maquette)

Maquette **premium** de la nouvelle homepage Schréder : hero full-height immersif,
effet verre (glassmorphism), typographie **Work Sans** légère, ton de marque « Sage »,
tout en minuscules (hors noms propres / produits).

## Aperçu

- `index.html` — la homepage
- `css/styles.css` — styles
- `js/main.js` — interactions (logo, header transparent → solide au scroll, menu mobile placeholder)
- `assets/` — logos + images de fond (voir `assets/README.md`)
- `.github/workflows/deploy-pages.yml` — déploiement GitHub Pages (auto au push)

En ligne : **https://alcegobe.github.io/SchrederWebsite/**

## Structure de la homepage

1. hero (full-height, photo + verre)
2. preuve (chiffres clés)
3. notre approche (3 bénéfices)
4. trouver son point de départ (besoins + audiences)
5. plateforme — Schréder EXEDRA
6. études de cas (verre sur fond sombre)
7. sustainability (immersif sombre + verre · 3 piliers)
8. insights
9. CTA final
10. footer
