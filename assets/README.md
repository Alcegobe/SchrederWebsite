# assets/

Déposez ici les fichiers de marque.

## Images de fond (hero & sustainability)

Déposez (mêmes étapes que ci-dessous) :

```
assets/hero.jpg            → fond du hero (.jpg / .png / .webp acceptés)
assets/sustainability.jpg  → fond de la section sustainability (nature / nuit)
```

Tant qu'une image est absente, un fond dégradé de repli s'affiche.

## Logo

La maquette charge automatiquement deux variantes :

```
assets/Logo-Schreder-Black-Left.svg   → header (fond clair)
assets/Logo-Schreder-White-Left.svg   → footer (fond sombre)
```

➡️ **Pour ajouter les logos :** sur GitHub, branche `claude/happy-shannon-k0xiud`,
« Add file » → « Upload files », déposez les fichiers dans le dossier `assets/`
en conservant exactement ces noms.

Chaque variante présente remplace le logo texte correspondant ; tant qu'un fichier
est absent, le logo texte de repli s'affiche — rien ne casse.

> Astuce : un SVG est du texte. Si l'upload est bloqué, ouvrez le fichier dans un
> éditeur, copiez tout son contenu et collez-le dans le chat — le fichier sera créé.
