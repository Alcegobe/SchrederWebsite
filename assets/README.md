# assets/

Déposez ici les fichiers de marque.

## Logo

La maquette charge automatiquement :

```
assets/Logo-Schreder-Black-Left.svg
```

➡️ **Pour ajouter le logo :** sur GitHub, branche `claude/happy-shannon-k0xiud`,
« Add file » → « Upload files », déposez votre fichier dans le dossier `assets/`
en conservant le nom **`Logo-Schreder-Black-Left.svg`**.

Dès qu'il est présent, il remplace le logo texte dans le header (et le footer).
Tant qu'il est absent, le logo texte de repli s'affiche — rien ne casse.

> Note : le footer est sombre. Le logo « Black » y est affiché en blanc via un
> filtre CSS provisoire. Si vous avez une version blanche (`Logo-Schreder-White-Left.svg`),
> dites-le-moi et je câble la bonne variante pour le footer.
